# Plugin Oficial — Vida de Bloco v2 (`@VidadeBlocoBR`)

Agentes e Skill de produção automatizada v2 de vídeos animados em blocos 2D/2.5D no formato **"E se...?"** para o canal **Vida de Bloco (`@VidadeBlocoBR`)**.

## Agentes incluídos neste plugin (`plugin-vida-de-bloco/`)
- **`vida-de-bloco`** (Diretor Chefe & Produtor v2 — Agente Principal e Subagente).
- **`analista-tendencias`** (Pesquisa vídeos virais, compara com o canal e alimenta `dados/tendencias.md`).
- **`gestor-canal`** (Organização do canal, resposta a comentários, análise de críticas e radar de vídeos com mais likes).

## Equipe Auxiliar de Apoio (`plugin-levi-motion/` no repositório)
Instalada automaticamente junto via `.\instalar_agente.ps1`:
- `revisao-01`, `personagens-01`, `pecas-01`, `movimento-01`, `cenas-01`, `cor-01`, `som-01`, `texto-01`, `voz-01`, `codigo-01`.
