# Plugin Oficial — Vida de Bloco (`@VidadeBlocoBR`)

Agente e Skill de produção automatizada de vídeos animados em blocos 2D/2.5D no formato **"E se...?"** para o canal **Vida de Bloco (`@VidadeBlocoBR`)**.

## O que inclui
- **Agente `vida-de-bloco`** (disponível como Agente Principal e Subagente).
- **Skill `vida-de-bloco`** com todo o pipeline:
  - Roteiros originais `"E se...?"` (Shorts 9:16 e Longos 16:9);
  - Rigs proporcionais (`204x186` / `156x164`) sem conflito de acessórios;
  - Cenários em camadas + HUDs estilo Roblox;
  - Narração multi-voz isolada por vídeo + legenda sincronizada palavra por palavra (`WordBoundary`);
  - Geração de thumbnails `1280x720` e `1080x1920`;
  - Auditoria visual quadro a quadro com `revisao-01`;
  - Trava obrigatória de aprovação humana antes do upload na API do YouTube.
